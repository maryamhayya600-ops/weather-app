# 🌤️ Weather App

A simple weather application built with HTML, CSS, and JavaScript using the OpenWeatherMap API.

---

## 🚀 Features
- Search for any city
- Real-time weather data
- Temperature in Celsius
- Weather description
- Humidity display
- Weather icons

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeatherMap API
